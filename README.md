# VEX Central
A comprehensive scouting, collaboration, and autonomous simulation platform designed for competitive VEX Robotics teams.


## Live Demo


- Live Deployment Link: [vex-central.vercel.app](http://vex-central.vercel.app)


## Overview
VEX Central solves a major challenge for competitive robotics teams: organizing scouting data, coordinating alliance strategy, and validating autonomous routines are often scattered across spreadsheets, various chatting apps, and separate simulators.


This project brings those capabilities together in one polished app. Teams can create competitions, assign match scouting tasks, compare team performance, and simulate autonomous routines all in one place.


## Core Features


- Advanced 2D Autonomous Simulator
- Match Scout & Analytics
- Real-Time Team Workspace


## Tech Stack


- Framework: Next.js / React
- Styling & UI: Tailwind CSS
- Backend & Database: Firebase (Firestore)
- Hosting: Vercel

## Getting Started (Local Installation)


1. Clone the repository:
   git clone[](https://github.com/your-username/vex-central.git)[https://github.com/TheKrakenRulez/VEX-Central.git](https://github.com/TheKrakenRulez/VEX-Central.git)


   cd vex-central


2. Install dependencies:
   npm install


3. Configure environment variables:


- Create a .env.local file at the project root.
- Add your Firebase configuration values.


4. Start the development server:
   npm run dev


5. Open the app in your browser:
   http://localhost:3000
